# Calculadora com Compose
Projeto 4 Bimestre de Programção para Dispositivos Móveis
Desenvolvido por: Ernany Victor, Nicollas de Souza e Karine Flores

## Recursos
- Adição, subtração, multiplicação e divisão.
- Tratamento de divisão por zero (mensagem `Erro`).
- Porcentagem e Raiz quadrada.
- Histórico dos últimos 8 cálculos.
